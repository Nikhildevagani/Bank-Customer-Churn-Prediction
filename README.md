# 🏦 Bank Customer Churn Prediction

An end-to-end Machine Learning project that predicts whether a bank customer is likely to churn.

## 🚀 Project Overview

This project uses customer demographic, financial, and engagement information to predict customer churn.

### Machine Learning Models

- Logistic Regression
- Random Forest
- XGBoost

### Final Model

XGBoost with an optimized classification threshold of 0.30.

## 📊 Final Performance

| Metric | Score |
|---|---:|
| Accuracy | 84.50% |
| Precision | 61.10% |
| Recall | 65.60% |
| F1 Score | 63.27% |
| ROC-AUC | 86.31% |
| Classification Threshold | 0.30 |
